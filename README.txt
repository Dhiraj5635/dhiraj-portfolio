DHIRAJ RAHANGDALE — CYBER / ENGINEERING STUDENT PORTFOLIO

FILES
- index.html: page content, profile details, skills, projects, education, contact.
- style.css: cyber theme, colors, layout, and mobile responsiveness.
- script.js: updates the footer year.
- assets/: put your photo and resume here.

RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use Live Server.

PERSONALIZE index.html
- Photo: add your own image as assets/profile-photo.jpg.
- Email: replace every occurrence of your.email@example.com.
- Phone: replace +91XXXXXXXXXX in the link and +91 XXXXX XXXXX in the visible text.
- GitHub / LinkedIn: replace placeholder profile links.
- Resume: add your PDF as assets/Dhiraj-Rahangdale-Resume.pdf.
- Skills: keep only technologies you actually know or are learning.
- Projects: currently shown as concepts; update status after you build them.
